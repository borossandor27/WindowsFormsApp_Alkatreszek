# WindowsFormsApp_Alkatreszek

## SQLite adatbázis adminisztrálás

Nekem nagyon bejön a [DB Browser](https://sqlitebrowser.org/dl/)

## Kompatibilitás

A .NETFramework esetében sok problémám volt a `Microsoft.Data.SQlite` névtérrel. Helyette ajánlom a `System.Data.SQLite` névteret, amely a `NuGet` segítségével beilleszthető.
